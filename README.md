# Tip Calculator

Enter the bill amount and a tip percentage, and see the tip and the total.

**Live demo:** https://YOUR-USERNAME.github.io/tip-calculator/

![Tip Calculator screenshot](Tip-Calculator.png)

## Example

| Bill | Tip % | Tip | Total |
|---|---|---|---|
| ₹500 | 10% | ₹50.00 | ₹550.00 |
| ₹1250 | 15% | ₹187.50 | ₹1437.50 |

## Features

- Works out the tip and the total with one click
- Results shown with 2 decimal places
- Works on phones and computers

## Built with

- HTML
- CSS
- JavaScript (no libraries)

## What I learned

- Reading input values and turning text into numbers with `Number()`
- Doing the maths in JavaScript
- Formatting results with `toFixed(2)`
- Reading the inputs inside the click handler, so the latest values are used

## Run it on your computer

1. Download or clone this repo
2. Open `index.html` in your browser
